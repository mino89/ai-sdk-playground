# AI sdk playground

This repository is a playground for learning purposes with [ai-sdk](https://ai-sdk.dev/).

## Getting Started

install dependencies:

```bash
pnpm install
```

copy the `.env.example` file to `.env` and set your environment variables:

## Available Scripts

In the project directory, you can run:

### `pnpm dev`

Runs the app in the development mode.

### `pnpm watch`

Watches for changes in the `src` folder and compiles the code automatically.

### `pnpm devtools``

Runs the ai-sdk devtools for inspecting requests and responses.
